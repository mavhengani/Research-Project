# Research artifacts

This directory contains audit and provenance metadata, frozen Candidate 2 identities, batch artifacts, and U1/U2 smoke checkpoints. Large checkpoint files are stored through Git LFS. Clone with Git LFS installed and run `git lfs pull` before attempting checkpoint reloads.

The strict-corpus manifest records the expected 110,615 records and the corpus checksum. The source manifests record the prepared-source counts. Verify hashes and run the project validation commands before resuming research execution. Do not regenerate or edit the approved Candidate 2 freeze to replace missing artifacts.
