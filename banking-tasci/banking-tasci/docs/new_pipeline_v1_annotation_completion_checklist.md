# New-pipeline annotation completion checklist

- [ ] Work from the approved Candidate 2 batch and verified checksum.
- [ ] Preserve record ID, source/provenance fields, text, context and privacy fields.
- [ ] Set one allowed primary intent and Boolean public-warning flag.
- [ ] Add zero, one or more valid opinions as warranted.
- [ ] Check target and opinion phrase offsets against the immutable text.
- [ ] Use canonical `ENTITY#ATTRIBUTE` category values and allowed sentiment.
- [ ] Save a safe dated backup outside the approved batch path.
- [ ] Run the submission validator and resolve every error.
- [ ] Record ambiguous decisions by record ID in the decision log.
